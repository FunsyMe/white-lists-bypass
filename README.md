## Обход белых списков через Yandex CDN + 3X-UI
В этой статье мы разберем способ обхода белых списков через Yandex CDN вместе с популярной панелью 3x-ui. Для начала работы нам понадобится любой домен, VPS сервер с панелью 3x-ui и зарегистрированный аккаунт на [Yandex Cloud](https://yandex.cloud/). В качестве опреационной системы будет использован Debian 12 под root пользователем.

## Подготовка домена и Yandex Cloud
Для начала перейдите в настройки домена и создайте DNS-запись, которая будет вести на IP вашего VPS сервера:
| Тип | Имя | Адресс        |
|-----|-----|---------------|
| A   | @   | ip_вашего_vps |

Следующим шагом будет создание сертификата Let's Encrypt для домена. Перейдите на [Console Yandex Cloud](https://console.yandex.cloud/), в левом верхнем углу выберите _"Все сервисы"_ → _"Безопасность"_ → _"Certificate Manager"_. Следом _"Добавить сертификат"_ → _"Сертификат Let's Encrypt"_:
| Имя         | Домены        | Тип проверки |
|-------------|---------------|--------------|
| любой_текст | cdn.ваш_домен | DNS          |

После того как сертификат будет создан, нажмите по нему и пролистните страницу вниз до пункта _"Проверка прав на домены"_. Убедитесь что активен пункт "CNAME-запись" и запомните пункты "Имя", "Значение". Далее нужно сново перейдти а настройки домена и создать DNS-запись, которая будет ссылать на CDN Yandex:
| Тип   | Имя                | Значение                |
|-------|------------------- |-------------------------|
| CNAME | имя_из_пункта_выше | значение_из_пункта_выше |

Данный шаг может занять от 5 до 60 минут в зависимости регистратора домена. После ожидания, пункт _"Статус"_ у вашего сертификата в _"Certificate Manager"_ должен стать _"Issued"_. Если этого не произошло, повторно проверьте все настройки.
